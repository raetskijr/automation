# backup.sh

Вариация скрипта резервного копирования. Делает то же самое, что и
`backup.sh`, но оформлена в другом стиле: все сообщения выводятся с
пометками `[ИНФО]` / `[ОШИБКА]` / `[ГОТОВО]`, а обработка ошибок
вынесена в отдельную функцию `fail()`.

## Использование

```bash
chmod +x backup.sh
./backup.sh <исходная_директория> [директория_для_бэкапа]
```

- **`<исходная_директория>`** — что архивируем (обязательно).
- **`[директория_для_бэкапа]`** — куда положить архив (необязательно,
  по умолчанию `/backup`).

## Примеры

```bash
./backup.sh ~/documents ~/backups
./backup.sh ~/documents
```

## Формат имени архива

```
backup-<имя_папки>-<ГГГГММДД_ЧЧММСС>.tar.gz
```

Например: `backup-documents-20260914_172311.tar.gz`

## Проверки и обработка ошибок

Все ошибки идут через единую функцию `fail()`, которая печатает
сообщение с пометкой `[ОШИБКА]` в stderr и завершает скрипт с кодом 1.
Проверяются:

- наличие первого аргумента (исходной директории);
- существование исходной директории;
- существование директории назначения (если её нет — создаётся
  автоматически через `mkdir -p`);
- права на запись в директорию назначения.

Если при архивации происходит сбой, недописанный `.tar.gz`-файл
удаляется.

## Требования

- Bash (используется `#!/usr/bin/env bash`)
- Утилиты `tar`, `date`, `mkdir`, `basename`, `dirname`
