# lab01 — backup.sh

### Что это

Скрипт делает бэкап папки в архив `tar.gz`. В имени архива есть дата, типа `saves-25.10.2026.tar.gz`.
Внутри архива лежит сама папка (`saves/...`), без длинных абсолютных путей.

### Как запустить

```bash
chmod +x backup.sh
./backup.sh <что бэкапить> [куда]
```

- первый аргумент — папка, которую бэкапим (обязательно);
- второй — куда класть архив, если не указать, то `/backup`.

Если папки нет (любой из двух), скрипт ругается в stderr и выходит с кодом 1.
Слэш в конце пути не мешает: `saves/` тоже норм.
Если запустить два раза за день, архив просто перезапишется (раз в день хватит).

### Примеры

Забыл аргумент:

```
$ ./backup.sh
Эй, а что бэкапить? Пример: ./backup.sh ~/games/saves [куда]
$ echo $?
1
```

Опечатался в пути:

```
$ ./backup.sh games/save dump
Упс, папки "games/save" нет. Проверь путь.
```

Нормальный запуск (со слэшем в конце, всё ок):

```
$ ./backup.sh games/saves/ dump
Готово! -> dump/saves-25.10.2026.tar.gz
```

С домашней папкой то же самое: `./backup.sh ~/games/saves /tmp/dump`.

### Если ругается на /backup

```
$ ./backup.sh games/saves
Папки "/backup" нет. Создай её (sudo mkdir /backup) и попробуй снова.
```

Сам скрипт папку не создаёт. Создай её один раз, а сам бэкап в неё запускай через sudo:

```bash
sudo mkdir /backup
sudo ./backup.sh games/saves
```
