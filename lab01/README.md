# lab01: backup.sh

### Что это

Скрипт делает резервную копию папки в архив `tar.gz`. В имени архива есть дата, например `saves-25.10.2026.tar.gz`.
Внутри архива лежит сама папка (`saves/...`), без длинных абсолютных путей.

### Как запустить

```bash
chmod +x backup.sh
./backup.sh <какую папку сохранить> [куда]
```

- первый аргумент: папка, которую сохраняем (обязательно);
- второй: куда положить архив, если не указать, то `/backup`.

Если папки нет (любой из двух), скрипт пишет ошибку в stderr и выходит с кодом 1.
Слэш в конце пути не мешает: `saves/` тоже подходит.
Если запустить два раза за день, архив просто перезапишется (одной копии в день достаточно).

### Примеры

Без аргумента:

```
$ ./backup.sh
Не указана папка для резервной копии. Пример: ./backup.sh ~/games/saves [куда]
$ echo $?
1
```

Ошибка в пути:

```
$ ./backup.sh games/save dump
Папка "games/save" не найдена. Проверьте путь.
```

Обычный запуск (со слэшем в конце, всё работает):

```
$ ./backup.sh games/saves/ dump
Готово: dump/saves-25.10.2026.tar.gz
```

С домашней папкой то же самое: `./backup.sh ~/games/saves /tmp/dump`.

### Если нет папки /backup

```
$ ./backup.sh games/saves
Папка "/backup" не найдена. Создайте её (sudo mkdir /backup) и запустите скрипт снова.
```

Сам скрипт папку не создаёт. Её нужно создать один раз, а сам скрипт запускать через sudo:

```bash
sudo mkdir /backup
sudo ./backup.sh games/saves
```
